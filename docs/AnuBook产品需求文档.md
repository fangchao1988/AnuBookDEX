## 一、文档概述

### 1.1 文档目的

明确AnuBook整体产品定位、用户画像、功能需求、交互规则、非功能需求、迭代规划、运营规则，作为项目研发、测试、上线、迭代的统一依据。

### 1.2 产品定位

ANUBIS 生态原生 AI+隐私 专业订单簿DEX，以全链路隐私保护为基础、AI智能交易策略引擎为核心、专业订单/杠杆/暗池为载体、ZK分级合规为保障，服务专业交易员、量化团队、机构大户，打造集智能决策、隐私交易、风险管控、机构服务于一体的综合性DeFi交易平台。

### 1.3 核心目标

1. **业务目标**：上线6个月累计用户≥10000人，专业交易者占比≥60%，累计交易量≥10亿美元
2. **技术目标**：实现ZK+MPC全链路隐私、链下AI离线运算、链上加密执行，交易延迟<10ms，ZK证明生成<3s
3. **生态目标**：与RocketSwap流动性互通，完善ANUBIS交易生态矩阵，树立AI+隐私DeFi标杆

### 1.4 术语定义

| 术语 | 释义 |
|------|------|
| ZK-SNARK | 零知识证明，实现订单、地址、仓位加密隐私 |
| MPC | 安全多方计算，用于暗池匿名撮合 |
| AI策略引擎 | 链下独立部署，行情研判、智能挂单、风控预警，运算数据不上链 |
| 冰山订单 | 大额订单自动拆分，隐藏真实挂单体量，防仓位狙击 |
| ZK-KYC | 分级隐私合规体系，小额匿名、大额可选择性合规披露 |
| 链下撮合 | 订单匹配在链下内存池完成，仅结算数据上链，降低Gas、提升速度 |

## 二、用户分析

### 2.1 核心用户画像

#### 2.1.1 专业个人交易者（核心C端用户）

- 特征：熟悉合约、杠杆、限价/止损订单，高频交易，重视交易策略隐私，惧怕MEV、仓位狙击
- 核心诉求：智能点位推荐、自动防狙击挂单、实时风控减仓、交易行为匿名

#### 2.1.2 量化交易团队

- 特征：使用程序化策略交易，核心算法为核心资产，严禁泄露
- 核心诉求：策略离线托管、加密指令上链、AI辅助策略优化、低延迟接口

#### 2.1.3 机构/大额资金用户（B端用户）

- 特征：单笔交易额大，易冲击盘面，有合规审计需求
- 核心诉求：隐私暗池撮合、零滑点、ZK分级合规、机构专属后台

#### 2.1.4 流动性提供者（LP/做市商）

- 特征：为订单簿提供深度，追求收益与资金安全
- 核心诉求：AI智能流动性调度、手续费分红、隐私资产托管

### 2.2 用户痛点

1. 链上交易透明，订单、仓位、策略极易被窃取，MEV与仓位狙击频发
2. 人工分析行情、设置止盈止损效率低，杠杆爆仓风险高
3. 量化策略上链存在泄露风险，无法保护核心知识产权
4. 大额交易冲击盘面，滑点高，缺少安全匿名的大额交易通道
5. 隐私交易与监管合规难以平衡，限制机构资金入场

## 四、详细功能需求（PRD核心）

### 4.1 账户与钱包模块

#### 4.1.1 钱包连接

- 支持ANUBIS生态主流钱包一键连接
- 连接后地址默认隐私加密展示，可手动切换明文/匿名模式
- 支持多钱包切换、会话超时自动登出

#### 4.1.2 账户中心

- 展示总资产、可用余额、持仓、杠杆仓位、累计盈亏
- 隐私设置：全局交易匿名开关、地址隐身、订单隐藏
- NFT权益识别：自动识别ANUBIS生态NFT，解锁手续费/AI服务折扣

### 4.2 AI智能交易策略引擎（核心创新模块）

> 规则：AI全量运算在链下隔离环境完成，仅加密交易指令上链，策略与原始数据永不公开

#### 4.2.1 AI智能行情研判 & 点位推荐

1. 实时抓取盘口深度、资金流向、多币种行情、市场舆情
2. AI自动计算并展示：最优买入价、卖出价、止盈价、止损价
3. 支持一键填入推荐点位至下单面板
4. 行情标签：看涨/看跌/震荡、风险等级提示

#### 4.2.2 AI防狙击智能挂单

1. 针对大额挂单，自动拆分冰山订单，分批分时挂单
2. 动态调整委托档位、挂单节奏，规避MEV机器人与仓位猎杀
3. 支持用户手动开启/关闭智能拆单功能
4. 挂单全程加密，链上仅展示聚合结果，不暴露原始体量

#### 4.2.3 策略离线隐私托管

1. 用户自定义交易策略、量化脚本本地/链下运行
2. AI模型参数、策略逻辑不上链、不落地明文存储
3. 支持策略启停、历史策略管理、策略快照备份
4. 权限隔离：仅账户本人可查看与操作自有策略

#### 4.2.4 AI杠杆实时智能风控

1. 7×24小时监控杠杆账户保证金比例、强平价格、风险系数
2. 风险分级提醒：正常/警示/高危/濒临爆仓
3. 自动执行风控动作（可手动开关）：
   - 高危状态：隐私减仓、部分止盈
   - 濒临爆仓：自动对冲或平仓，规避资产损失
4. 风控日志加密存储，仅本人可见

#### 4.2.5 AI智能交易路由

1. 自动比对 AnuBook 订单簿 与 RocketSwap 流动性池深度
2. 算法择优选择撮合路径，最小化交易滑点
3. 跨平台路由交易统一记账、统一手续费统计

### 4.3 隐私订单簿交易模块

#### 4.3.1 订单簿视图

- 买卖盘深度图表、最新成交价、24H涨跌、成交量
- 盘口数据加密脱敏展示，不泄露真实大额委托
- 区分普通订单 / AI智能拆分订单标签

#### 4.3.2 全品类专业订单

支持以下订单类型，所有订单信息（价格、数量、方向）ZK加密：

1. **限价单**：基础买卖委托
2. **止损单 / 止盈单**：触发价格自动成交
3. **冰山订单**：手动大额拆单（与AI智能拆单并行）
4. **条件单**：组合行情触发委托

#### 4.3.3 我的订单

- 未成交、已成交、已撤销订单分类展示
- 订单哈希可链上溯源，原始订单信息加密
- 支持批量撤销未成交订单

### 4.4 杠杆交易模块

1. 杠杆档位：支持 1–10 倍杠杆自由选择
2. 加密保证金：保证金余额、持仓仓位全链路隐私加密
3. 借贷利息：按持仓时长计费，利息明细清晰展示
4. 强制平仓规则：达到强平线自动平仓，同步触发AI风控记录
5. 与AI风控引擎深度联动，风险实时预警

### 4.5 机构级暗池撮合模块（B端专属）

1. 入口：区分普通交易区 / 暗池大额交易区
2. MPC匿名撮合：订单在加密计算网络内匹配，不对外展示
3. 零滑点撮合机制，避免大额交易冲击盘面
4. 暗池交易记录加密归档，支持机构合规对账
5. 大额交易收取暗池专项服务费

### 4.6 ZK分级合规模块

#### 4.6.1 分级隐私规则

1. **小额交易**：完全匿名，无需KYC
2. **大额交易**：触发ZK-KYC引导，用户自主选择披露范围

#### 4.6.2 审计与监管接口

1. 预留ANUBIS官方审计接口、监管视图密钥
2. 可追溯交易行为，但不泄露用户隐私、AI策略与原始订单
3. 自动生成合规报表，满足AML、GDPR、区域性监管要求

### 4.7 生态协同与流动性模块

#### 4.7.1 双向流动性互通

- AnuBook 订单簿 ↔ RocketSwap AMM 池资产互通
- AI路由统一调度流动性，提升全域资金利用率

#### 4.7.2 LP流动性挖矿

1. 支持为交易对提供流动性，获取平台手续费分红+生态代币奖励
2. AI智能测算最优做市配比，辅助LP配置资产
3. 流动性仓位隐私加密保护

#### 4.7.3 NFT权益体系

- 持有ANUBIS生态NFT：交易手续费减免、AI高级功能折扣、杠杆利率优惠
- NFT权益自动识别、自动生效

### 4.8 资产、账单与日志

1. 资产总览：现货资产、杠杆持仓、流动性资产分类统计
2. 交易账单：成交记录、手续费、利息、暗池服务费明细
3. AI运行日志：行情分析记录、风控动作、智能挂单记录
4. 所有日志支持导出，本地加密保存

### 4.9 运营与激励模块

1. 新手引导：AI功能、隐私设置、杠杆使用教程
2. 活动中心：交易挖矿、AI体验活动、机构合作活动
3. 公告系统：版本更新、规则变更、风控提示、生态通知

## 五、非功能需求（NFR）

### 5.1 性能需求

1. 订单簿刷新频率：≤1s
2. 链下撮合响应延迟：<10ms
3. ZK证明生成时间：<3s
4. AI行情分析与点位推荐响应：<2s
5. 系统并发：支持千人同时在线交易，订单撮合无卡顿

### 5.2 安全需求

1. 智能合约：上线前完成多轮第三方安全审计，漏洞零容忍
2. 隐私安全：订单、地址、仓位、AI策略全程加密，禁止明文存储/传输
3. 防攻击：抵御MEV、女巫攻击、恶意挂单、刷单行为
4. 数据安全：AI运算数据、用户隐私数据隔离存储，权限严格管控

### 5.3 兼容性需求

1. 前端：主流Chrome、Edge、Safari浏览器，适配PC端（优先）
2. 钱包：兼容ANUBIS生态全系钱包
3. 底层：完全兼容ANUBIS Chain EVM、Obscura隐私协议

### 5.4 易用性需求

1. 专业模式/简易模式一键切换，兼顾新手与专业用户
2. AI功能入口醒目，一键应用推荐点位、智能挂单
3. 风险操作（高倍杠杆、大额暗池）增加二次确认与风险提示

### 5.5 可扩展性需求

1. 模块松耦合，后续可快速叠加衍生品、策略商店、跨链交易
2. AI模型支持在线迭代、版本升级，不中断交易服务
3. 合规体系可灵活适配不同地区监管政策

## 八、风控与运营规则

### 8.1 交易风控规则

1. 杠杆仓位达到80%风险线：弹窗提醒+AI主动预警
2. 达到90%高危线：AI自动开启部分减仓（用户可关闭）
3. 单笔大额交易强制二次确认，引导使用暗池通道

### 8.2 收费规则（对应盈利模式）

1. **常规交易**：基础手续费，NFT持有者梯度减免
2. **杠杆交易**：交易手续费 + 每日借贷利息
3. **暗池大额交易**：固定服务费 + 超额比例佣金
4. **AI高级策略服务**：基础功能免费，高阶策略/量化托管增值收费

### 8.3 合规运营规则

1. 严格执行ZK分级隐私策略，不强制收集用户隐私信息
2. 定期提交合规报表至ANUBIS Foundation
3. 封禁恶意刷单、攻击、洗钱类地址
